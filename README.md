# Ping Pong (Raylib)

Hello! This game is made especially for Windows using Raylib. It relies on external dependencies, so it may not work as simply as copying and running the code. I’ve included a full VSCode setup in the project for Windows users.

The main menu and game screens were designed in Photoshop so the visuals and code fit together in a clean, synchronized style.

Hope you like it.

## Key Features

- Single-player mode: Play against AI opponents of varying difficulty levels.
- Multiplayer mode: Play with a friend on the same device.
- Customizable difficulty: Adjust the AI’s skill level to your preference.
- Simple controls: Anyone can play it within seconds.
- Eye-catching visuals: Colorful graphics and a consistent theme.
- Sound design: Sound effects add atmosphere and feedback.
- Efficient code: The game is implemented in a compact, focused codebase.
- Leaderboard: Single-player shows the top 3 scores and names using file handling.

## Other Info

- Programming language: C++
- Game engine: Raylib
- Game design: Levels, modes, and mechanics are tuned for a fun experience.
- Art assets: High-quality graphics created with Photoshop and Paint.
- Testing and debugging: Thorough testing was done to improve gameplay and fix bugs.
